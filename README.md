# CareerTrack – Smart Job Application & Career Management System

CareerTrack is a web-based application designed to help job seekers manage their job search, track applications, prepare for interviews, and analyze their skills against job requirements.

## Features

- User registration and login
- Add, edit, delete, and manage job applications
- Search and filter applications
- Dashboard with application statistics
- Follow-up date tracking
- Interview preparation tracker
- Resume upload (PDF and TXT)
- Automatic candidate skill extraction
- Job description skill extraction
- Skill matching analysis
- Matched skills, missing skills, and match percentage

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- pypdf

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/ranadeep04/CareerTracker.git`

2. Navigate into the project folder.

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `py app.py`

5. Open your browser and visit:

   `http://127.0.0.1:5000`

## Project Purpose

The purpose of CareerTrack is to provide a single platform for managing job applications and career preparation instead of maintaining multiple spreadsheets or notes.
